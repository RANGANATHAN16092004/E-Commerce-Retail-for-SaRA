# VRS Fashion Hub 👗✨

VRS Fashion Hub is a modern single-vendor fashion e-commerce platform built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). The platform allows customers to browse and purchase trendy fashion products online while providing a secure hidden admin dashboard for product and order management.

## 🚀 Features

### Customer Features

* User Authentication (JWT)
* Browse Products by Category
* Search & Filter Dresses
* Product Details Page
* Add to Cart & Wishlist
* Secure Checkout
* Razorpay Payment Integration
* Order History & Tracking
* Responsive Mobile-Friendly UI
* Product Reviews & Ratings

### Admin Features (Private)

* Hidden Admin Login
* Secure Admin Dashboard
* Add/Edit/Delete Products
* Manage Orders & Inventory
* Sales Analytics Dashboard
* Coupon Management
* User Management
* Protected Routes & Role-Based Access

## 🛠️ Tech Stack

### Frontend

* React.js

* React Router DOM
* Axios
* Framer Motion

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

### Integrations

* Cloudinary (Image Upload)
* Razorpay (Payments)

## 🔒 Security

* JWT Authentication
* Password Hashing
* Admin Route Protection
* Role-Based Authorization

## 📦 Installation

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm start
```
